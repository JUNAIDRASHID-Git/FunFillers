# FunFillers - Mobile & Web User App

FunFillers E-Commerce Toy & Game Store Flutter Application.

## Key Features
- **Product Catalog & Categories**: Horizontal category scroll, product search, filtering, and responsive grid layout.
- **Product Details & Deep Linking**: Integrated `GoRouter` for `/product/:id` deep linking and routing.
- **Open Graph Product Sharing**: Native share dialog and copy link option formatted with Open Graph preview URLs.
- **Cart & Wishlist**: Real-time state management via Flutter BLoC.
- **Live Go Backend Integration**: Connected to live Render backend (`https://ff-backend-klec.onrender.com`).

## Getting Started
```bash
flutter pub get
flutter run
```
